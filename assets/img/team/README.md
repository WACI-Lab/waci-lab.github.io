Drop team member photo files here (e.g. `mengqi-jia.jpg`), then reference them
in `_data/team.yml` via `photo: /assets/img/team/mengqi-jia.jpg` on that
person's entry. Anyone without a `photo:` set keeps the initials avatar.

Recommended: square images, at least 400x400px, cropped to the face/shoulders
(cards use `object-fit: cover` so off-square images will be center-cropped).
